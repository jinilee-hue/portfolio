포트폴리오 디자인 시안 3종

세 시안 모두 같은 실제 데이터(GitHub 공개 저장소 14개 · 실제 배포 화면 캡처)를 렌더한다. 다른 건 구성과 태도뿐이다. 한/영 토글, 라이트·다크 자동 전환, 키보드 포커스는 세 안에 모두 들어 있다.

공통으로 피한 것: 인디고~퍼플 그래디언트, Inter 본문, 아이콘+제목+두 줄 3단 카드 그리드, 글래스모피즘, 4열 푸터 — 2026년 기준 'AI가 만든 사이트' 판별 신호로 카탈로그된 항목들이다. 한글 제목은 라틴 디스플레이 서체에 글리프가 없어 명조로 폴백되므로, 세 안 모두 :lang(ko)에서 Pretendard 굵기 대비로 전환한다.

Variant A

Editorial Ink

종이 질감의 웜 뉴트럴 위에 세리프 표제. 프로젝트를 카드가 아니라 목록 행으로 쌓고, 썸네일은 흑백으로 두었다가 호버에서 색이 돌아온다.

서체
Instrument Serif + Pretendard
색
웜 페이퍼 / 테라코타 액센트
구조
에디토리얼 인덱스
인상
차분함, 읽는 사람

이럴 때 좋다 — 케이스 스터디를 글로 길게 쓸 생각이라면. 가장 안전하고 오래 간다. 대신 '기술적으로 뭘 하는 사람인지'는 약하게 보인다.

Variant B

Spec Ledger

다크 모노크롬 + 애시드 라임 하나. 작업을 표(ledger)로 세우고 스택 필터를 달았다. 배포 개수·라이브 비율·최근 갱신을 첫 화면에서 숫자로 박는다.

서체
Bricolage + IBM Plex Mono + Pretendard
색
차콜 / 라임 #C6F24E
구조
필터 가능한 원장 테이블
인상
도구를 만드는 사람

이럴 때 좋다 — "디자이너인데 실제로 배포한다"를 가장 세게 증명한다. 14개를 한 화면에서 훑게 해줘서 양이 곧 설득이 된다. 다크 개발자 톤이 취향에 안 맞으면 부담.

Variant C

Screen Room

화면이 주인공. 실제 배포 캡처를 큰 판형으로 어긋나게 쌓고 설명은 옆에 붙인다. 상단 바는 blend mode로 배경 위를 지나간다.

서체
Fraunces + Archivo + Pretendard
색
근사 블랙 / 민트 #00E5C0
구조
전면 스크린샷 스택
인상
비주얼 디자이너

이럴 때 좋다 — 만든 화면 자체가 예쁠 때 가장 강하다. 다만 스크롤이 길고, 썸네일 품질이 그대로 실력으로 읽히니 캡처를 계속 관리해야 한다.
